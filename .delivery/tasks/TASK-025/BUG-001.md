# BUG-001 Strict schema contract chưa được enforce bằng Zod/runtime parser

## Expected behavior

Frontend CR-004 phải consume machine-verifiable dataset contract theo TASK-021. File `frontend/src/contracts/api/dataset.schema.ts` dự kiến phải có Zod schemas hoặc runtime parser tương đương cho `ApiResponse`, `ObjectLabel`, `DatasetSource`, `BBoxSample`, `ZoneSyncResult` và các response envelope. Client service phải parse/validate response trước khi cấp dữ liệu cho UI.

## Actual behavior

`frontend/src/contracts/api/dataset.schema.ts` chỉ khai báo TypeScript type/interface. `frontend/src/services/api.ts` cast JSON response bằng `as ApiResponse<T>` trong `readDatasetJson()` và không validate runtime shape. `npm --prefix frontend ls zod` cho kết quả dependency rỗng, nên Zod không có trong frontend package.

## Reproduction

1. Chạy `npm --prefix frontend ls zod`.
2. Quan sát kết quả `sentri-ai-mini-frontend@0.1.0 ... \n└── (empty)`.
3. Chạy `rg -n "zod|parse\\(|safeParse|dataset\\.schema|readDatasetJson|ApiResponse" frontend\\src`.
4. Quan sát chỉ có `ApiResponse` type/interface và cast trong `readDatasetJson()`, không có schema parse/safeParse.

## Evidence

- `frontend/src/contracts/api/dataset.schema.ts` định nghĩa interfaces, không import `zod`.
- `frontend/src/services/api.ts:66` đọc JSON và cast thành `ApiResponse<T>`.
- `npm --prefix frontend ls zod` exit code 1 với kết quả package không có dependency `zod`.
- `rg` không tìm thấy `safeParse` hoặc Zod parser cho dataset API.

## Impact

Nếu backend trả thiếu/sai field trong CR-004 dataset APIs, frontend có thể vẫn coi response là hợp lệ đến khi UI lỗi ở runtime. Điều này vi phạm yêu cầu strict schema contract adherence của skill verification và machine-verifiable TypeScript/Zod contract trong TASK-021.

## Suggested owner

Frontend implementation owner (`implement-frontend`) hoặc API contract integration owner.

## Scope note

Verification task không sửa production code. Cần dispatch fix riêng để thêm runtime schema validation hoặc cập nhật approved contract nếu project chấp nhận chỉ dùng static TypeScript types.
