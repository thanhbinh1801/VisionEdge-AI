# BUG-001 — Vision pipeline misclassifies a utility pole as `Xe cẩu`

- Severity: major
- Affected requirements: `REQ-002`, `REQ-004`
- Affected tasks: `TASK-007`

## Expected

The area vision pipeline should classify fixed scene structures such as poles or columns as ignored background, not as one of the 8 monitored object classes.

## Actual

In the `BAI-KIEM` scene, a vertical pole/column is sometimes detected as `Xe cẩu` (`crane`). This creates a false positive object and cần cascade into incorrect zone state, event feed entries, and operator confusion.

## Reproduction

1. Open the area dashboard for camera `BAI-KIEM`.
2. Observe the tall vertical pole near the right side of the frame.
3. Wait for the detector to classify that structure.
4. Notice that it cần be labeled as `Xe cẩu` instead of being ignored as static background.

## Evidence

- The open-vocabulary prompt set explicitly includes crane-like prompts:
  - [vision_pipeline.py](D:/Hilab/Project34/backend/app/services/vision_pipeline.py:43)
  - [vision_pipeline.py](D:/Hilab/Project34/backend/app/services/vision_pipeline.py:47)
- The pipeline also knows background-pole prompts, but only ignores them when the raw class matches those exact prompt labels:
  - [vision_pipeline.py](D:/Hilab/Project34/backend/app/services/vision_pipeline.py:52)
  - [vision_pipeline.py](D:/Hilab/Project34/backend/app/services/vision_pipeline.py:78)
- Current false-positive suppression for `crane` is narrow:
  - [vision_pipeline.py](D:/Hilab/Project34/backend/app/services/vision_pipeline.py:265) only drops ultra-thin vertical crane boxes with width `< 2.5%`
- Any wider pole-like structure that the model names as `crane`, `port crane`, or related prompt cần still pass through as a valid canonical detection.

## Root Cause

The misclassification originates in the core AI vision pipeline. `TASK-007` owns the logic that maps raw open-vocabulary detections into the canonical 8 classes. The current design combines:

- permissive crane-oriented prompts for port equipment
- exact-match ignore rules for pole-like prompts
- a very narrow geometric suppression rule for thin vertical `crane` detections

That combination leaves a gap where a static pole cần be predicted with a crane-related label and survive filtering, producing a false positive `crane`.
