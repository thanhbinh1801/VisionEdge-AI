# BUG-002 — WebSocket metadata loop keeps sending after connection failure

- Severity: major
- Affected requirements: `REQ-002`, `REQ-004`, `REQ-009`
- Affected tasks: `TASK-017`

## Expected

Sau khi client dong hoac mat ket noi WebSocket `/ws/v1/events`, backend phai dung vong lap publisher, cleanup connection, va khong tiep tuc `send` tren socket da hong.

## Actual

Backend accept va mo ket noi thanh cong, nhung sau do log lap lai `socket.send() raised exception.` nhieu lan. Hien tuong nay cho thay publisher loop van co gang day payload metadata vao mot socket da fail thay vi thoat vong lap va disconnect sach se.

## Reproduction

1. Chay backend FastAPI bang `backend/main.py` trong moi truong da co `fastapi`, `uvicorn`, va WebSocket transport.
2. Ket noi toi `ws://localhost:8000/ws/v1/events?camera_id=BAI-KIEM&conf_threshold=0.35`.
3. Quan sat log backend:
   - `WebSocket /ws/v1/events?... [accepted]`
   - `connection open`
4. De client dong socket, bi unmount, hoac bi thay the boi reconnect.
5. Quan sat log backend tiep tuc in lap lai `socket.send() raised exception.`

## Minimal Failing Case

- Public seam nho nhat la vong lap trong `websocket_events_endpoint`.
- Ket noi duoc accept thanh cong, nen mismatch route-contract da duoc loai tru.
- Chi can mot send-failure sau khi socket khong con kha dung la du de cho thay vong lap hien tai khong thoat ra va khong cleanup connection ngay.

  - Nhung cac lifecycle do khong giai thich viec server tiep tuc gui vao socket da fail; day van la resilience gap phia backend

## Root Cause

Nguyen nhan goc nam o vong lap publisher trong `backend/app/api/v1/websocket.py`. Sau khi ket noi duoc accept, endpoint lien tuc tao payload va `send_text` len mot `WebSocket` cu the. Khi client dong ket noi hoac send bi loi o tang transport, code hien tai khong xu ly du cac send-failure nay de break loop va `disconnect` ngay. Vi endpoint chi bat `WebSocketDisconnect`, mot so truong hop socket hong sau accept se roi vao trang thai server tiep tuc co gang gui va de Uvicorn log `socket.send() raised exception.` lap lai.
